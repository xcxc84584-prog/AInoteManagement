# BV-Text v4.9.7 — HRC 資源診斷與一致性修正

- 保留單一 HRC 模式、Explorer、目錄化、分割、提交。
- 從 Python 瀏覽器移除殘留的插入圖片介面與檔案上傳流程。
- 以 SVG 檔案內容辨識 MIME，避免歷史紀錄錯誤 MIME 導致無法顯示。

注意：這是針對可辨識 SVG 與失敗診斷的增量修正；ChatGPT 若未在剪貼簿提供圖形像素或 SVG，仍無法重建。手機端真實渲染需要實機驗證。
